# 抖音直播伴侣定时开关播设计

## 目标

在现有 Electron 应用中增加一个 Windows 与 macOS 均可使用的“定时开关播”功能。用户设置直播时长后启动任务，应用自动操作抖音直播伴侣开播；只有确认直播已成功开始后才启动倒计时，到时自动完成关播及二次确认。

首版只支持单次任务。应用必须保持运行；应用退出或电脑重启后不恢复任务。

## 用户流程

1. 用户输入直播时长，采用“小时 + 分钟”两个数字输入框。
2. 用户点击“启动任务”。应用校验总时长大于零，并检查抖音直播伴侣是否正在运行。
3. 应用自动恢复直播伴侣窗口并置于前台，定位并点击“开始直播”。
4. 应用轮询直播伴侣状态。检测到“正在直播”或可用的“关播”控件后，记录实际开播时间并启动倒计时。
5. 倒计时结束时，应用再次恢复直播伴侣窗口并置于前台，点击“关播”。
6. 出现“结束直播”确认框后，应用点击“关闭直播”。
7. 应用检测到界面恢复为可用的“开始直播”状态后，将任务标记为完成。

运行中的页面显示当前阶段、实际开播时间和剩余时间，并提供“取消任务”。取消只停止自动化和倒计时，不主动结束已经开始的直播。

## 技术方案

自动化逻辑运行在 Electron 主进程，通过类型化 IPC 与渲染进程通信。渲染进程负责收集配置、展示状态和发送启动/取消命令；页面切换不影响主进程中的任务。

主进程提供统一的 `LiveCompanionDriver` 接口，包含以下能力：

- 查找直播伴侣进程与窗口。
- 恢复、激活并置顶目标窗口。
- 读取当前直播状态。
- 点击开始直播。
- 点击关播并处理“关闭直播”确认框。

Windows 驱动优先使用 UI Automation，macOS 驱动优先使用 Accessibility API。控件无法通过辅助功能树识别时，两端均回退到窗口截图和 OpenCV 模板匹配，在目标窗口坐标系内定位按钮后执行鼠标点击。不能可靠定位目标时不得点击。

macOS 首次使用前必须获得“辅助功能”和“屏幕录制”权限；Windows 在目标应用以管理员权限运行时，本应用也需要相同权限级别，否则显示明确错误。

## 状态机

任务状态固定为：

- `idle`：无任务。
- `starting`：正在定位窗口并尝试开播。
- `waitingForLive`：已点击开播，等待确认直播状态。
- `countingDown`：直播已确认，正在倒计时。
- `stopping`：正在点击关播及确认按钮。
- `verifyingStopped`：等待确认直播已经结束。
- `completed`：已确认结束直播。
- `cancelled`：用户取消任务。
- `failed`：自动化失败，保存可展示的失败原因。

任何时刻最多存在一个任务。开始、关播和状态验证分别设置有限超时；超时后进入 `failed`，不得继续盲目点击。

## 状态识别与点击保护

辅助功能树是首选的控件定位和状态识别来源。图像回退使用“窗口级截图 + 多模板匹配”，至少覆盖“开始直播”“关播”“关闭直播”三种控件；模板按操作系统和显示缩放分类。

每次点击前必须同时满足：

- 已确认目标窗口属于抖音直播伴侣。
- 目标控件位于当前目标窗口范围内。
- 匹配结果达到设定置信度，并且不存在多个含义不明的候选。
- 当前任务状态允许该操作，例如只有 `stopping` 才能点击“关闭直播”。

点击后必须通过状态变化验证结果。验证失败时允许有限次数重新识别，但不在未知位置重复点击。

## 界面

在现有应用中增加紧凑的“定时开关播”区域：

- 小时与分钟数字输入框；分钟限制为 `0-59`，小时为非负整数，总时长必须大于零。
- “启动任务”主按钮。
- 运行时展示阶段、剩余时间和“取消任务”按钮，并锁定时长输入。
- 失败时展示具体原因和重新尝试入口。
- 首次缺少系统权限时展示操作系统对应的授权说明。

启动任务前提示应用将自动切换并置顶直播伴侣窗口。首版不支持预约未来时间、多段任务、循环开关播或退出后恢复。

## 错误处理

以下情况直接停止自动化并进入 `failed`：

- 未找到抖音直播伴侣进程或窗口。
- 缺少辅助功能、屏幕录制或权限级别不足。
- 无法唯一定位目标按钮。
- 点击开播后未在超时时间内确认直播状态。
- 到时后无法打开或处理结束直播确认框。
- 点击“关闭直播”后未确认恢复为未开播状态。

错误信息应说明失败阶段和建议操作。已经开播后发生关播失败时，界面必须醒目提示用户立即手动关播。

## 测试与验收

- 单元测试覆盖时长校验、状态机转换、倒计时起点、取消行为、超时和重试限制。
- 驱动接口使用模拟实现测试成功开播、开播失败、关播确认失败和状态验证失败。
- Windows 与 macOS 分别验证辅助功能定位路径和图像回退路径。
- 验证窗口处于后台、被遮挡和最小化时能自动恢复并置于前台。
- 验证倒计时只在确认“正在直播”后开始。
- 验证关播依次点击“关播”和“关闭直播”，并以恢复“开始直播”状态作为完成条件。
- 验证取消任务不会主动关闭正在进行的直播。
- 运行项目的格式检查、类型检查和自动化测试。
